# 📝 Flask To-Do App

A simple and user-friendly **To-Do List web application** built using **Flask** and **SQLite**. This application helps users manage their daily tasks by allowing them to add, update, complete, and delete tasks.

## 🚀 Features

* ➕ Add new tasks
* ✏️ Update existing tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 📋 View all tasks
* 💾 Store tasks using SQLite
* 🎨 Clean and simple user interface

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* Jinja2

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/flask-todo-app.git
```

### 2. Open the project folder

```bash
cd flask-todo-app
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
