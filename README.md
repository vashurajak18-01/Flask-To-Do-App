# 📝 Flask To-Do App

A simple task management web application built using **Flask** and **SQLite**. Users can add, update, complete, and delete daily tasks through a clean interface.

## 🚀 Features

* Add new tasks
* Update tasks
* Mark tasks as completed
* Delete tasks
* Store data using SQLite

## 🛠️ Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS

## ▶️ Run the Project

```bash
pip install flask
python app.py
```

Open:

```text
http://127.0.0.1:5000/
```
